# Contributing to ExamDwar

Thanks for helping improve ExamDwar! This repository is the public resource hub for the ExamDwar sarkari-jobs portal.

## Ways to contribute

- **Report a bug / broken link** — open an [issue](https://github.com/toolifyra/examdwar/issues) with the exact URL.
- **Suggest a correction** — exam dates, vacancies, eligibility or category link errors.
- **Improve this repo** — fix the README, `docs/index.html` styling, or add useful assets.

## Pull request guide

1. Fork the repository.
2. Make changes on a new branch (`feature/my-change`).
3. Keep changes focused and readable.
4. Verify links in `README.md` and `docs/index.html` point to live URLs.
5. Open a pull request describing what and why.

## Content guidelines

- Keep Hindi + English text natural (Hinglish is fine for edu content).
- Do **not** add personal contact/internal details.
- Links should point to official sources or examdwar.com.
